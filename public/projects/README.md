# Imágenes de proyectos

Cada galería utiliza cuatro imágenes WebP con relación recomendada de `16:10` y dimensiones de al menos `1200 x 750 px`.

## Rutas esperadas

```text
public/projects/nia/fase-01.webp
public/projects/nia/fase-02.webp
public/projects/nia/fase-03.webp
public/projects/nia/fase-04.webp

public/projects/rcg/fase-01.webp

public/projects/rcg/fase-03.webp
public/projects/rcg/fase-04.webp

public/projects/sgi/fase-01.webp
public/projects/sgi/fase-02.webp
public/projects/sgi/fase-03.webp
public/projects/sgi/fase-04.webp
```

Las fases corresponden a concepto, desarrollo, prototipo y resultado. Después de agregar una imagen, cambie su propiedad `available` a `true` en `src/data/projects.js`.
